# Institutional Logo Assets

Place your official institutional logo image files in this folder (`/public/logos/`):

1. **Shivaji College Logo**
   - **Path**: `/public/logos/shivaji-college-logo.png`
   - **File format**: PNG with transparent background (or JPG/SVG)
   - **Used in**: Left side of the Journal Masthead and College Institutional sections

2. **University of Delhi Logo**
   - **Path**: `/public/logos/delhi-university-logo.png`
   - **File format**: PNG with transparent background (or JPG/SVG)
   - **Used in**: Right side of the Journal Masthead and Academic Affiliation sections

3. **(Optional) Campus Hero Photograph**
   - **Path**: `/public/logos/campus-photo.jpg`
   - **File format**: High-resolution JPG or PNG

The application automatically loads these images as soon as they are placed in this folder.
If an image file is not present, a dignified institutional vector seal is shown as an automatic fallback.
